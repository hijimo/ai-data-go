## 使用指南

### 快速开始

1. **设置环境变量**：
```bash
export AZURE_OPENAI_API_KEY="your-api-key"
export AZURE_OPENAI_BASE_URL="https://your-resource.openai.azure.com"
```

2. **运行基本示例**：
```bash
go run internal/genkit/plugins/azure/examples/basic_usage.go
```

3. **查看文档**：
```bash
# 主文档
cat internal/genkit/plugins/azure/README.md

# 示例文档
cat internal/genkit/plugins/azure/examples/README.md
```

### 学习路径

1. **初学者**：
   - 阅读主 README 的"快速开始"部分
   - 运行 `basic_usage.go` 示例
   - 尝试修改示例代码

2. **进阶用户**：

   - 学习工具调用（`tool_calling_example.go`）
   - 学习错误处理（`error_handling_example.go`）
