# 流式输出快速参考

## 数据结构速查

### TencentCloudStreamMessage

```go
type TencentCloudStreamMessage struct {
    CompletionID      string             // 对话唯一标识
    SessionID         string             // 会话ID（可选）
    Processes         ProcessInfo        // 处理过程信息
    DeltaContent      string             // 增量内容（输出阶段）
    Content           string             // 完整内容（finish事件）
    FinishReason      string             // 结束原因：stop/error
    IsStop            bool               // 是否停止
    AnswerSource      string             // 答案来源（可选）
    AdditionalContent *AdditionalContent // 附加内容（可选）
}
```

### ProcessInfo

```go
type ProcessInfo struct {
    Stage        StreamStage // 当前阶段
    Message      string      // 阶段描述
    DeltaContent string      // 增量内容（思考阶段）
    Content      string      // 完整内容
    Detail       interface{} // 详细信息
}
```

## 阶段类型速查

| Stage | 说明 | Detail 类型 | 使用场景 |
|-------|------|------------|---------|
| `tool_call_start` | 开始调用工具 | `ToolCallDetail` | 工具调用开始 |
| `tool_call_progress` | 工具调用进行中 | `ToolCallDetail` | 显示进度 |
| `tool_call_complete` | 工具调用完成 | `ToolCallDetail` | 工具返回结果 |
| `tool_call_error` | 工具调用失败 | `ToolCallDetail` | 工具调用错误 |
| `internal_searching` | 正在搜索 | `SearchDetail` | 知识库搜索中 |
| `finished_internal_searching` | 搜索完成 | `SearchDetail` | 搜索结果返回 |
| `resource_retrieval_start` | 开始检索资源 | `ResourceRetrievalDetail` | 资源检索开始 |
| `resource_retrieval_complete` | 资源检索完成 | `ResourceRetrievalDetail` | 资源检索完成 |
| `thinking` | 正在思考 | `nil` | 显示思考过程 |
| `""` (空) | 正式输出 | `nil` | 输出最终内容 |

### 客户端：处理消息

```javascript
eventSource.addEventListener('message', (event) => {
  const data = JSON.parse(event.data);
  
  // 根据阶段处理
  switch (data.processes.stage) {
    case 'thinking':
      showThinking(data.processes.delta_content);
      break;
    case '':
      appendContent(data.delta_content);
      break;
  }
  
  // 检查是否完成
  if (data.is_stop) {
    if (data.finish_reason === 'error') {
      showError(data.processes.message);
    }
    eventSource.close();
  }
});

eventSource.addEventListener('finish', (event) => {
  const data = JSON.parse(event.data);
  showFullContent(data.content);
});
```

## 常用判断逻辑

### 判断消息类型

```go
// 是否是思考阶段
if msg.Processes.Stage == model.StreamStageThinking {
    // 处理思考内容：msg.Processes.DeltaContent
}

// 是否是正式输出
if msg.Processes.Stage == model.StreamStageOutput {
    // 处理输出内容：msg.DeltaContent
}

// 是否是工具调用
if msg.Processes.Stage == model.StreamStageToolCallStart {
    // 处理工具调用
}

// 是否是搜索
if msg.Processes.Stage == model.StreamStageInternalSearching {
    // 处理搜索状态
}
```

### 判断流结束

```go
// 是否停止
if msg.IsStop {
    // 流结束
}

// 是否成功完成
if msg.IsStop && msg.FinishReason == "stop" {
    // 成功完成
}

// 是否出错
if msg.IsStop && msg.FinishReason == "error" {
    // 出错，错误信息在 msg.Processes.Message
}
```

## 性能优化建议

1. **缓冲区大小**: 创建通道时设置合适的缓冲区

   ```go
   outputChan := make(chan *model.TencentCloudStreamMessage, 10)
   ```

2. **立即刷新**: 每次写入后立即刷新

   ```go
   flusher.Flush()
   ```

3. **批量发送**: 对于小块内容可以批量累积后发送

   ```go
   if len(buffer) > 10 {
       sendChunk(buffer)
       buffer = ""
   }
   ```

4. **超时控制**: 设置合理的超时时间

   ```go
   ctx, cancel := context.WithTimeout(ctx, 30*time.Second)
   defer cancel()
   ```

## 常见问题速查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 内容不显示 | 未刷新缓冲区 | 调用 `flusher.Flush()` |
| 连接断开 | 超时或网络问题 | 增加超时时间，添加重连逻辑 |
| 内容乱序 | 并发问题 | 使用序列号或单线程处理 |
| 内存泄漏 | 通道未关闭 | 确保 `defer close(outputChan)` |
| 客户端收不到 | CORS 问题 | 设置正确的 CORS 头 |
