# 流式输出重构说明

## 概述

本次重构将流式输出格式从简单的事件模式升级为腾讯云流格式，提供更丰富的流程状态信息和更好的扩展性。

## 主要变更

### 1. 新增数据结构 (`internal/model/stream.go`)

#### 核心类型

- **`TencentCloudStreamMessage`**: 腾讯云流式消息的完整格式
- **`StreamStage`**: 流式输出阶段枚举
- **`ProcessInfo`**: 处理过程信息
- **`AdditionalContent`**: 附加内容（引用文档、搜索结果等）

#### 支持的阶段类型

**工具调用相关**:

- `tool_call_start` - 开始调用工具
- `tool_call_progress` - 工具调用进行中
- `tool_call_complete` - 工具调用完成
- `tool_call_error` - 工具调用失败

**搜索/检索相关**:

- `internal_searching` - 正在搜索知识库
- `finished_internal_searching` - 搜索完成
- `resource_retrieval_start` - 开始检索资源
- `resource_retrieval_complete` - 资源检索完成

**生成相关**:

- `thinking` - 正在思考
- `""` (空字符串) - 正式输出

### 2. 接口变更

#### AI服务接口 (`internal/service/ai/service.go`)

```go
// 旧接口
ChatStream(ctx context.Context, req *model.ChatRequest) (<-chan model.StreamChunk, error)

// 新接口
ChatStream(ctx context.Context, req *model.ChatRequest) (<-chan *model.TencentCloudStreamMessage, error)
```

#### 消息服务接口 (`internal/service/session/message_service.go`)

```go
// 旧接口
SendMessageStream(ctx context.Context, req *SendMessageRequest) (<-chan *StreamMessageChunk, error)

// 新接口
SendMessageStream(ctx context.Context, req *SendMessageRequest) (<-chan *model.TencentCloudStreamMessage, error)
```

### 3. SSE 输出格式

#### 旧格式

```
data: {"event":"content","content":"你好"}

data: {"event":"done","done":true}
```

#### 新格式（腾讯云）

```
data: {"completion_id":"session-123","processes":{"stage":"","message":""},"delta_content":"你好","is_stop":false}

event: finish
data: {"completion_id":"session-123","session_id":"session-123","processes":{"stage":"","message":""},"content":"你好，我是AI助手","finish_reason":"stop","is_stop":true}
```

### 4. 实现细节

#### AI服务实现 (`internal/service/ai/genkit_service.go`)

- 将 Genkit 的流式输出转换为腾讯云格式
- 累积完整内容用于 finish 事件
- 支持错误处理和上下文取消

#### 消息服务实现 (`internal/service/session/message_service.go`)

- 直接转发腾讯云格式的消息
- 累积内容用于保存到数据库
- 更新会话信息

#### 处理器实现 (`internal/api/handler/message_handler.go`)

- 支持 `event: finish` 格式
- 正确处理 SSE 事件类型
- 根据 `is_stop` 字段判断流结束

## 数据流程

```
用户请求
  ↓
MessageHandler.SendMessageStream
  ↓
MessageService.SendMessageStream
  ├─ 保存用户消息
  ├─ 创建AI消息记录
  └─ 调用 AIService.ChatStream
      ↓
GenkitService.ChatStream
  ├─ 调用 Genkit 流式生成
  └─ 转换为腾讯云格式
      ↓
MessageService 接收并转发
  ├─ 累积内容
  └─ 更新数据库
      ↓
MessageHandler 输出 SSE
  └─ 客户端接收
```

## 扩展点

### 1. 工具调用支持

当需要支持工具调用时，可以在 AI 服务中添加：

```go
// 发送工具调用开始事件
outputChan <- &model.TencentCloudStreamMessage{
    CompletionID: sessionID,
    Processes: model.ProcessInfo{
        Stage:   model.StreamStageToolCallStart,
        Message: "正在调用搜索工具...",
        Detail: &model.ToolCallDetail{
            ToolName: "search_docs",
            ToolID:   "tool-001",
        },
    },
    IsStop: false,
}

// 发送工具调用完成事件
outputChan <- &model.TencentCloudStreamMessage{
    CompletionID: sessionID,
    Processes: model.ProcessInfo{
        Stage:   model.StreamStageToolCallComplete,
        Message: "工具调用完成",
        Detail: &model.ToolCallDetail{
            ToolName: "search_docs",
            ToolID:   "tool-001",
            Result: &model.ToolCallResult{
                Status: "success",
                Data:   searchResults,
            },
        },
    },
    IsStop: false,
}
```

### 2. 搜索/检索支持

```go
// 发送搜索开始事件
outputChan <- &model.TencentCloudStreamMessage{
    CompletionID: sessionID,
    Processes: model.ProcessInfo{
        Stage:   model.StreamStageInternalSearching,
        Message: "正在搜索知识库...",
        Detail: &model.SearchDetail{
            SpaceName: "技术文档",
        },
    },
    IsStop: false,
}

// 发送搜索完成事件
outputChan <- &model.TencentCloudStreamMessage{
    CompletionID: sessionID,
    Processes: model.ProcessInfo{
        Stage:   model.StreamStageFinishedInternalSearching,
        Message: "搜索到 14 篇资料",
        Detail: &model.SearchDetail{
            SpaceName:  "技术文档",
            SpaceCount: 1,
            DocCount:   14,
        },
    },
    AdditionalContent: &model.AdditionalContent{
        ReferenceChunks: referenceChunks,
    },
    IsStop: false,
}
```

### 3. 思考过程支持

```go
// 发送思考过程
outputChan <- &model.TencentCloudStreamMessage{
    CompletionID: sessionID,
    Processes: model.ProcessInfo{
        Stage:        model.StreamStageThinking,
        Message:      "正在根据资料进行深度思考...",
        DeltaContent: "首先", // 思考过程的增量文本
    },
    IsStop: false,
}
```

## 向后兼容性

- 保留了旧的 `StreamChunk` 和 `StreamMessageChunk` 类型，标记为已废弃
- 建议新代码使用 `TencentCloudStreamMessage`
- 旧的客户端需要更新以支持新格式

## 注意事项

1. **CompletionID**: 当前使用 sessionID 作为 completionID，未来可以改为每次对话生成唯一ID
2. **SessionID**: 在 finish 事件中返回，流程中可能为空
3. **AnswerSource**: 当前固定为 "ai-model"，未来可以根据实际来源设置
4. **AdditionalContent**: 当前未使用，预留用于引用文档、搜索结果等

## 迁移指南

### 客户端更新

**旧格式解析**:

```javascript
eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.event === 'content') {
    appendContent(data.content);
  } else if (data.event === 'done') {
    finishStream();
  }
};
```

**新格式解析**:

```javascript
eventSource.addEventListener('data', (event) => {
  const data = JSON.parse(event.data);
  
  // 处理不同阶段
  switch (data.processes.stage) {
    case 'thinking':
      showThinking(data.processes.delta_content);
      break;
    case '':
      appendContent(data.delta_content);
      break;
  }
  
  if (data.is_stop) {
    finishStream();
  }
});

eventSource.addEventListener('finish', (event) => {
  const data = JSON.parse(event.data);
  showFullContent(data.content);
  finishStream();
});
```
