## 任务执行说明

### 执行顺序

任务应按照编号顺序执行，因为后续任务依赖于前面任务的完成。

### 可选任务

标记为 `*` 的任务为可选任务（主要是测试相关），可以根据项目需求决定是否执行。

### 验证要点

每个任务完成后，应验证：

1. 代码编译无错误
2. 相关的单元测试通过
3. 不影响现有功能

### 注意事项

1. 在修改服务层和Handler层时，要特别注意权限验证逻辑的正确性
2. 删除代码前，确保没有其他地方引用
3. 更新Swagger注释时，要确保与实际实现一致
4. 所有权限相关的修改都应该有对应的测试覆盖
