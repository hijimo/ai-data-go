# 错误场景测试快速参考

## 概述

错误场景测试验证系统在各种异常情况下的错误处理能力，确保系统能够正确识别和报告错误。

## 测试文件

- **测试文件**: `test/e2e/error_scenarios_test.go`
- **测试脚本**: `test/test_error_scenarios.sh`

## 运行测试

### 使用测试脚本

```bash
./test/test_error_scenarios.sh
```

### 直接运行 Go 测试

```bash
go test -v ./test/e2e -run TestErrorScenarios
```

### 跳过长时间运行的测试

```bash
go test -v -short ./test/e2e -run TestErrorScenarios
```

## 测试覆盖的错误场景

### 1. 配置相关错误

#### 1.1 配置不存在

- **场景**: 请求不存在的模型配置
- **预期**: 返回"模型配置不存在"错误
- **验证**: 错误消息包含"模型配置"

#### 1.2 模型已禁用

- **场景**: 请求已禁用的模型配置
- **预期**: 返回"模型已禁用"错误
- **验证**: 错误消息包含"模型已禁用"

#### 1.3 模型已删除

- **场景**: 请求已软删除的模型配置
- **预期**: 返回"模型配置不存在"错误（已删除的配置被视为不存在）
- **验证**: 错误消息包含"模型配置"

#### 1.4 配置JSON格式错误

- **场景**: 模型配置的 QueryParams 字段包含无效的JSON
- **预期**: 返回JSON解析错误
- **验证**: 系统能够捕获并报告JSON格式错误

### 2. 租户相关错误

#### 2.1 租户ID为空

- **场景**: 请求时提供空字符串作为租户ID
- **预期**: 返回"租户ID无效"错误
- **验证**: 错误消息包含"租户ID"

#### 2.2 租户ID格式错误

- **场景**: 请求时提供无效的UUID格式
- **预期**: 返回"租户ID无效"错误
- **验证**: 错误消息包含"租户ID"

#### 2.3 租户ID不存在

- **场景**: 请求时提供不存在的租户ID
- **预期**: 返回"模型配置不存在"错误
- **验证**: 错误消息包含"模型配置"

### 3. API密钥相关错误

#### 3.1 API密钥为空

- **场景**: 模型配置的API密钥为空字符串
- **预期**: 返回API密钥相关错误
- **验证**: 系统能够检测到空API密钥

#### 3.2 API密钥无效

- **场景**: 模型配置的API密钥无效
- **预期**: API调用失败，返回认证错误
- **验证**: 系统能够捕获并报告API认证失败

### 4. 提供商相关错误

#### 4.1 不支持的提供商类型

- **场景**: 模型配置使用不支持的提供商类型
- **预期**: 返回"不支持的提供商"错误
- **验证**: 错误消息包含"不支持的提供商"

### 5. 参数相关错误

#### 5.1 Temperature参数为负数

- **场景**: 请求时提供负数的temperature参数
- **预期**: 某些提供商可能拒绝负数temperature
- **验证**: 记录提供商的行为

#### 5.2 Temperature参数超出范围

- **场景**: 请求时提供大于2的temperature参数
- **预期**: 某些提供商可能拒绝超出范围的temperature
- **验证**: 记录提供商的行为

#### 5.3 MaxTokens参数为负数

- **场景**: 请求时提供负数的maxTokens参数
- **预期**: 应该拒绝负数maxTokens
- **验证**: 记录提供商的行为

#### 5.4 MaxTokens参数为零

- **场景**: 请求时提供零作为maxTokens参数
- **预期**: 应该拒绝零maxTokens
- **验证**: 记录提供商的行为

### 6. 输入相关错误

#### 6.1 空提示词

- **场景**: 请求时提供空字符串作为提示词
- **预期**: 某些提供商可能拒绝空提示词
- **验证**: 记录提供商的行为

#### 6.2 超长提示词

- **场景**: 请求时提供超长的提示词（10000个字符）
- **预期**: 某些提供商可能拒绝超长提示词
- **验证**: 记录提供商的行为

### 7. 上下文相关错误

#### 7.1 上下文已取消

- **场景**: 在请求前取消上下文
- **预期**: 返回"context canceled"错误
- **验证**: 错误消息包含"context canceled"

#### 7.2 上下文超时

- **场景**: 设置极短的超时时间（1毫秒）
- **预期**: 返回"context deadline exceeded"错误
- **验证**: 错误消息包含"context deadline exceeded"

### 8. 流式调用错误

#### 8.1 流式调用 - 配置不存在

- **场景**: 流式调用不存在的模型配置
- **预期**: 返回"模型配置不存在"错误
- **验证**: 错误消息包含"模型配置"

#### 8.2 流式调用 - 租户ID无效

- **场景**: 流式调用时提供无效的租户ID
- **预期**: 返回"租户ID无效"错误
- **验证**: 错误消息包含"租户ID"

#### 8.3 流式调用 - 上下文取消

- **场景**: 在流式调用过程中取消上下文
- **预期**: 流式调用中断，正确处理取消
- **验证**: 系统能够优雅地处理流式中断

### 9. 并发错误场景

#### 9.1 并发调用不存在的模型

- **场景**: 多个并发请求调用不存在的模型
- **预期**: 所有请求都返回"模型配置不存在"错误
- **验证**: 并发场景下错误处理的一致性

#### 9.2 并发调用禁用的模型

- **场景**: 多个并发请求调用已禁用的模型
- **预期**: 所有请求都返回"模型已禁用"错误
- **验证**: 并发场景下错误处理的一致性

### 10. 边界条件

#### 10.1 模型名称包含特殊字符

- **场景**: 模型名称包含特殊字符和中文
- **预期**: 返回"模型配置不存在"错误
- **验证**: 系统能够处理特殊字符

#### 10.2 模型名称超长

- **场景**: 模型名称超过1000个字符
- **预期**: 返回"模型配置不存在"错误
- **验证**: 系统能够处理超长名称

### 需要注意的测试

某些测试会记录提供商的行为，而不是断言错误：

- **Temperature参数超出范围**: 不同提供商可能有不同的行为
- **MaxTokens参数为负数/零**: 不同提供商可能有不同的行为
- **空提示词**: 不同提供商可能有不同的行为
- **超长提示词**: 不同提供商可能有不同的行为

这些测试主要用于了解不同提供商的行为差异。

## 故障排查

### 测试失败：数据库连接错误

**问题**: 无法连接到测试数据库

**解决方案**:

1. 确认数据库服务正在运行
2. 检查数据库连接配置（DB_HOST, DB_PORT, DB_USER, DB_PASSWORD）
3. 确认测试数据库存在（DB_NAME）

### 测试被跳过：缺少API密钥

**问题**: 某些测试被跳过，提示"缺少有效的 API 密钥"

**解决方案**:

1. 设置至少一个有效的 API 密钥环境变量
2. 如果只想测试错误处理逻辑，可以忽略这些跳过的测试

### 测试超时

**问题**: 测试运行时间过长或超时

**解决方案**:

1. 增加测试超时时间：`go test -timeout 15m`
2. 检查网络连接是否正常
3. 检查API服务是否可用

## 最佳实践

### 1. 定期运行错误场景测试

在以下情况下运行错误场景测试：

- 修改错误处理逻辑后
- 添加新的提供商支持后
- 修改配置验证逻辑后
- 发布新版本前

### 2. 监控错误日志

错误场景测试会生成大量错误日志，这是正常的。关注：

- 错误消息是否清晰明确
- 错误类型是否正确
- 是否有意外的错误或崩溃

### 3. 测试覆盖率

确保错误场景测试覆盖：

- 所有可能的配置错误
- 所有可能的输入错误
- 所有可能的运行时错误
- 并发场景下的错误处理

### 4. 错误消息质量

验证错误消息：

- 包含足够的上下文信息
- 不泄露敏感信息（如API密钥）
- 对用户友好
- 便于调试

## 总结

错误场景测试是确保系统健壮性的重要组成部分。通过全面测试各种错误情况，我们可以：

1. **提高系统可靠性**: 确保系统在异常情况下不会崩溃
